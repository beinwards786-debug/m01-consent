M01 Exec Bridge - Privacy Policy

M01 Exec Bridge is a private tool used by a single owner to run the owner's own Google Apps Script research functions. It is not offered to the public.

It requests access to Google Sheets only for the owner's own account. It reads the owner's own spreadsheets only through a fixed, owner-controlled script. No data is sold, shared with third parties, or used for advertising. Google credentials are stored only on the owner's private server and can be revoked at any time at myaccount.google.com/permissions.
